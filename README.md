## 🎯 О проекте

SmartHen — система удалённого мониторинга и управления курятником в реальном времени. Проект решает задачу автоматизации фермерского хозяйства: владелец получает полную картину состояния курятника (вода, корм, температура, качество воздуха, количество яиц) без необходимости физического присутствия, плюс аналитику для принятия решений.

Backend собирает данные с датчиков (ESP32), хранит историю показаний и предоставляет REST API. Android-приложение визуализирует данные, присылает уведомления о критических состояниях и позволяет управлять курятником удалённо.

## ⚙️ Функционал

- 📊 **Мониторинг датчиков** — вода, корм, температура, отопление, качество воздуха в реальном времени
- 🥚 **Учёт яйценоскости** — сбор яиц, история по дням/месяцам, годовая аналитика с графиками
- 📹 **Видеонаблюдение** — управление камерой и записью
- 🔧 **Диагностика систем** — проверка онлайн/офлайн статуса всех датчиков
- 🔔 **Умные уведомления** — утренние/вечерние сводки, срочные алерты при критических показателях
- 🏠 **Мультикурятник** — привязка нескольких курятников через QR-код, переключение между ними
- 💳 **Система подписок** — тарифные планы (Базовый/Оптимум/Премиум)
- 🌗 **Тёмная тема + мультиязычность** (RU/EN)
- 📴 **Офлайн-режим** — кэширование последних данных при недоступности сервера

## 🚀 Установка и запуск

### Backend

1. Клонируй репозиторий:
```bash
git clone https://github.com/твой-username/SmartHen.git
cd SmartHen
```

2. Создай виртуальное окружение и активируй его:
```bash
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows
```

3. Установи зависимости:
```bash
pip install -r requirements.txt
```

4. Запусти сервер:
```bash
uvicorn main:app --reload
```

Сервер поднимется на `http://127.0.0.1:8000`, база данных `smarthen.db` создастся автоматически при первом запуске.

### Android-приложение

1. Открой папку `app/` в Android Studio
2. Дождись синхронизации Gradle
3. Проверь `RetrofitHelper.kt` — убедись, что `BASE_URL` указывает на адрес твоего backend (по умолчанию `http://10.0.2.2:8000/` — для эмулятора Android Studio)
4. Запусти приложение на эмуляторе или физическом устройстве (Min SDK 24)

## 🔌 API Endpoints

| Метод | Endpoint | Описание |
|---|---|---|
| GET | `/sensors/{coop_id}` | Получить датчики курятника |
| POST | `/sensors/{coop_id}/{sensor_id}` | Обновить показание датчика |
| POST | `/sensors/check/{coop_id}` | Проверить статус всех датчиков |
| GET | `/sensors/history/{coop_id}/{sensor_id}` | История показаний |
| GET | `/coops/list/{user_id}` | Список курятников пользователя |
| POST | `/coops/add` | Привязать курятник по QR-коду |
| POST | `/eggs/add` | Добавить яйца |
| POST | `/eggs/collect` | Собрать яйца |
| GET | `/eggs/stats/{coop_id}` | Статистика по дням |
| GET | `/eggs/monthly/{coop_id}` | Статистика по месяцам |
| GET | `/subscription/status/{user_id}` | Статус подписки |
